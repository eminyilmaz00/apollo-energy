# Apollo Green Solutions - Industrial Energy Management

A modern, visually impressive public-facing website built for an IoT-based energy management company serving B2B industrial clients.

## 🚀 Live Demo
**https://apollo-energy.vercel.app/**

## 🛠️ Tech Stack & Tools
As per the technical requirements, this project leverages a modern web stack:
*   **Framework:** Next.js 14 (App Router) and TypeScript for robust, scalable architecture.
*   **Styling:** Tailwind CSS for a clean, responsive, and professional B2B industrial design.
*   **Animations:** Framer Motion for smooth page transitions and micro-interactions.
*   **Deployment:** Vercel for fast, edge-network hosting.
*   **Version Control:** GitHub.
*   **Icons:** `lucide-react` for crisp, scalable industrial iconography.

## 📐 Design Decisions & Architecture
*   **Industrial B2B Aesthetic:** Opted for a "slate and green" color palette to convey reliability (slate/gray) and energy/sustainability (green).
*   **Performance & SEO:** Implemented Next.js Metadata API in the root layout for fundamental SEO (Title, Description, Open Graph tags). 
*   **Component Modularity:** Abstracted the Navigation and PageTransition logic into reusable components to keep the `app` directory clean.
*   **Client-Side Validation:** The Contact form utilizes React state to provide instant, user-friendly validation without unnecessary server calls.
